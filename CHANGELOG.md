## [1.0.0] - TBD

### Added
- Initial release
- Full Jetpack Compose support with `Modifier.shimmer()`
- `rememberShimmerState()` for state management
- `ShimmerBox()` convenience composable
- Traditional View system support with `ShimmerFrameLayout`
- XML attributes for easy configuration
- Programmatic API with Builder pattern
- Support for both alpha and color-based shimmer effects
- Linear and radial shimmer shapes
- Customizable direction, intensity, dropoff, and tilt
- Auto-start and lifecycle-aware animations
- Kotlin-first implementation
- Comprehensive documentation and examples

### Features
- **Min SDK**: 21 (Android 5.0)
- **Target SDK**: 35 (Android 15)
- **Kotlin**: 2.0.21
- **Compose**: 1.7.6
- **100% Kotlin** - No Java code
- **Modern Architecture** - Built with modern Android best practices

### Documentation
- Comprehensive README with usage examples
- Quick start guide
- Publishing guide for maintainers
- Sample app with various configurations
